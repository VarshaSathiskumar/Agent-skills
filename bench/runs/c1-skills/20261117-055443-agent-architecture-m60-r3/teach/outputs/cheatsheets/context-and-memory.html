Context and memory in an agent

From Lesson 1.

IdeaOne lineMakerspace example
Context windowAll text the model sees in one call: system prompt, tools, messages, tool results, its reply.Manual file on the server is invisible until a tool puts text in.
Conversation historyThe messages list your program resends every call; input cost grows each step.3 calls: 1,550 + 2,510 + 2,980 = 7,040 input tokens.
Context rotAccuracy falls as the window fills with clutter; window size is a ceiling, not a target.11 stale manual pages bury one line.
CompactionSummarize old history, continue from the summary; the prompt decides what survives.Keep goals, bookings, numbers.
NotesShort durable facts saved outside the window, loaded into the next session."dana: laser_training done".
RetrievalA search tool pulls only the needed chunks into context on demand; only as good as the search.search_manual("max acrylic thickness laser cutter").

Sorting question for any fact

Needed right now? Context. Must outlive the session? Notes. Reference material to look up? Retrieval. Live data that goes stale? Fetch with a tool, do not save.
