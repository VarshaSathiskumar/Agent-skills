# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context as a finite resource, compaction, note-taking memory and just-in-time retrieval. Use for: what to keep in context, what to save, what to fetch.
- [Docs: "Context windows" (Claude API docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official description of how the window is counted. Use for: window limits and what happens near them.
- [Article: "Introducing Contextual Retrieval" (Anthropic)](https://www.anthropic.com/engineering/contextual-retrieval)
  Retrieval over large knowledge bases and how chunking loses context. Use for: manual search design.
