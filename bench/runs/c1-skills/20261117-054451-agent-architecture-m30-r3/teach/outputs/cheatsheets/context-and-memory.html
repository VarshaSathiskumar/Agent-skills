Context and memory in an agent

From Lesson 1. The model sees only its request; everything else must be put there.

Rules to remember

  • Each model call resends the whole history, so requests grow and cost more per step.
  • Bigger window is not better memory: recall degrades as it fills (context rot), and the window empties between sessions.
  • Sorting test: how long must it live, how big is it, how often does it change?
  • Retrieval quality depends on the search: a missed page never reaches the model.
