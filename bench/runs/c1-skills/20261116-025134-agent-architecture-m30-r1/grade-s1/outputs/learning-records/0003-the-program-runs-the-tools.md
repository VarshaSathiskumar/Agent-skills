# Open misconception: Riley thinks the model runs the tools itself (M4)

In quiz 0001 (s1), Riley said the model opens the booking system and runs the three tools itself inside one call, so they counted 1 model call instead of 4.
Riley does understand the loop and the step-limit safeguard, and knows tools are chosen from names and descriptions, but also believed the model remembers its tool choices across sessions (M3).
