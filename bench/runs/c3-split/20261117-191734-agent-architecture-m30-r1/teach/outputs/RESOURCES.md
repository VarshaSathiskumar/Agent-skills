# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context rot, compaction, note-taking and just-in-time retrieval. Use for: what to keep in an agent's context and how to manage it.
- [Docs: "Context windows" (Claude Docs)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  What counts toward the window, history resent each turn, overflow errors. Use for: limits and what happens when the window fills.
- [Blog: "Context management" (Claude)](https://claude.com/blog/context-management)
  Context editing and the memory tool, with files stored on the developer's own infrastructure. Use for: how memory across sessions is stored.
