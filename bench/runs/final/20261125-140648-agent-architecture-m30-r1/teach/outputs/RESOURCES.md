# Agent architecture Resources

## Knowledge

- [Article: "Effective context engineering for AI agents" (Anthropic Engineering)](https://anthropic.com/engineering/effective-context-engineering-for-ai-agents)
  Primary source on context rot, compaction, clearing tool results, structured note-taking and just-in-time retrieval. Use for: what to keep in context, what to save, what to fetch.
- [Docs: "Context windows" (Claude Platform)](https://platform.claude.com/docs/en/build-with-claude/context-windows)
  Official definition of the context window, how history is resent each turn, overflow errors and token counting. Use for: window mechanics, limits and cost; also the table of real window sizes, which change.
