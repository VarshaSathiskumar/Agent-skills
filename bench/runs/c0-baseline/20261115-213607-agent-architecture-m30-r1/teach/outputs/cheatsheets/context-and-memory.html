Rules to remember

  • The model sees only its context; whatever is not in it, it cannot use.
  • The program re-sends the whole message list on every call, so cost grows with each step.
  • More context is not better (context rot): keep tool results small.
  • Too big: clear old tool results, compact (summarize), or use a sub-agent.
  • Nothing is kept between sessions unless the program saves it and loads it again.
  • Save what cannot be looked up; look up what can change.
  • Retrieval is a program-side search, started by a tool call, that puts relevant chunks into the context.
