# Misconception corrected: a language model does not remember past conversations by itself

Riley assumed a language model automatically remembers earlier conversations, so the makerspace assistant would recall what each student said last week. This was corrected: the model keeps nothing between calls, and any memory has to be saved by the application and put back into the model's input. Not yet shown: that Riley can restate this unprompted.

**Evidence:** chat message at the start of the context-and-memory topic.
**Implications:** the next lesson on context and memory should start from "the model only sees what is in the current input", then cover what the assistant saves per student and what it loads each session.
