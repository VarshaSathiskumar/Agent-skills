Riley still believed the model opens the booking system and runs the tools itself, with all three tool runs inside one model call (M4). Riley also said the model remembers earlier sessions on its own (M3).

**Implications:** Before building on the loop, fix the division of labour: the model writes a request, the program runs the tool and calls the model again.
