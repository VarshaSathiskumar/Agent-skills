# Misconception: a language model remembers past conversations on its own

Riley assumed the makerspace assistant would automatically remember what each student said last week. I corrected this: the model keeps nothing between calls, and anything it "remembers" is text the application saves and puts back into the next prompt.
Whether the correction landed is still open; a follow-up question was asked. The next lesson on context and memory can build on it.
