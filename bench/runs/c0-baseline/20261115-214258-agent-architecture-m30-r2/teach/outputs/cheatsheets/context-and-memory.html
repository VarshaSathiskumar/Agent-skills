Context and memory in an agent

From lesson 1.

Where information lives

PlaceLastsUse for
Context windowOne callSystem prompt, tool descriptions, transcript, tool results
Notes storeAcross sessionsPer-student facts, such as training status; load at session start
Searchable indexPermanentManuals; retrieve a few chunks on demand

Rules of thumb

  • The model remembers nothing; the program re-sends the transcript on every call.
  • Input tokens of call n = fixed part + all earlier requests and results. Total cost = sum over all calls.
  • A big tool result is paid for again on every later call: keep results small.
  • A fuller window costs more and recalls worse (context rot).
  • When it grows: clear old tool results, compact (summarize), or save notes.
  • Retrieval puts a few chunks in the window; it does not teach the model the manual. Debug it by checking what was in the context.

Source: Anthropic, Effective context engineering for AI agents.
