Success

200OK, result in body

Errors: whose fault?

400Malformed request
401Not authenticated
403Authenticated, not allowed
404No such resource
409Conflicts with current state
422Well-formed but invalid
500Server failed

Rules of thumb

  • Status code = outcome, never "it arrived", so no 200 with an error body.
  • Whole resource at a known URL: PUT. Some fields: PATCH. Server picks the ID: POST.
  • Retry is safe only for idempotent methods.
