# A language model does not remember earlier conversations on its own

Riley believed that a language model automatically remembers earlier conversations, so the makerspace assistant would recall what each student said last week.
This was corrected: the model sees only the text it is given in the current call, so any memory between sessions has to be saved by the program and put back into the input.

**Evidence:** Riley's check-in message in the chat, which stated the belief as fact.

**Implications:** Not yet confirmed that the correction landed; a follow-up question was asked.
