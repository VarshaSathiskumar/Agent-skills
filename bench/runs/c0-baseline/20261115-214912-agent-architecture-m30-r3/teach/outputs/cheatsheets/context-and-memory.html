Context and memory in an agent

From lesson 1.

Rules

  • The model keeps nothing between calls. The context, built by the program, is all it sees.
  • The context holds: system prompt, tool definitions, all messages, tool requests and results, and the output.
  • Every call re-sends the whole context: input tokens at call n = call n-1's input + the request + the result.
  • Bigger window does not mean better recall (context rot).
  • Nothing survives a session unless your program stores it and reloads it.

Retrieval

  • Chunk (a few hundred tokens), index, search, put the top few chunks in the context.
  • Embeddings find meaning; keyword search (BM25) finds exact codes. Combine them.
  • Long runs: compaction (summarize and continue), notes (files outside the context), sub-agents (clean context, short summary back).
