# REST API resources and URI design

The learner can explain that REST APIs organize data into resources and use URIs to identify and access them. They understand the difference between a collection endpoint, such as `/users`, and an individual resource endpoint, such as `/users/123`.

**Evidence:** In the earlier session, the learner practiced identifying resources and designing basic URIs for a web application. They showed a basic understanding of using resource names rather than actions in endpoint paths.

**Implications:** The learner understands basic resource and URI design (O1) but has not yet learned how to choose HTTP methods and status codes for different operations. The next lesson should focus on GET, POST, PUT, PATCH, idempotency, and common status codes (O2).
