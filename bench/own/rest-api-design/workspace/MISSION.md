# Mission

I want to learn REST API design so I can build reliable backend services for real-world applications. I have experience building small Python web applications and working with HTTP requests and JSON, but I want to understand how to design APIs properly rather than just consume them.

My goal is to design clear resource URLs, choose appropriate HTTP methods and status codes, and create consistent error responses that frontend applications can handle easily. I want to be able to explain and justify these design decisions when building a backend API.
